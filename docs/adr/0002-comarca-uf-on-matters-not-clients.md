# Comarca/UF lives on `matters`, not `clients`

The forensic-holiday-aware deadline engine (the product's core differentiator) needs to know which court jurisdiction a deadline belongs to, in order to pick the right national/state/comarca holiday calendar. It would be natural to put that location on `clients` (an address field), but a single client can have matters filed in different comarcas — so client-level location would silently miscalculate deadlines for any client with more than one forum. We're putting `uf` (required) and `comarca`/`municipio` (optional) directly on `matters`, and the deadline engine reads its parent matter's location, never the client's. This is foundational to schema + engine correctness, so getting it wrong ships a core-feature bug, not a cosmetic one.
