# No intra-tenant matter isolation in the MVP

LGPD/sigilo-profissional review raised whether one `advogado` should be blocked from seeing another `advogado`'s matters within the same tenant (the "escritório", per Estatuto da OAB art. 7º/34). We decided the MVP will not enforce this: RLS stays scoped to `tenant_id` only, and any user in a tenant can read/write any matter in that tenant. Reasoning: most small/medium escritórios work collaboratively by default, and building per-lawyer walls without a confirmed customer need would spend MVP time on a feature nobody asked for yet. Revisit if a design partner explicitly requires it — retrofitting is a real migration (row-level ownership + RLS policy changes + UI filtering), not a toggle, so treat this as deliberate, not an oversight.
